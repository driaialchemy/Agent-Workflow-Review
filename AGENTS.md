# AGENTS.md — Agent Safety Policy

> Draft generated by AIAlchemy Repo Governor for human review.

This file defines safety constraints for any AI agent working in **Agent-Workflow-Review**.

## Project

Offline Streamlit review board for AI workflow proposals.

## Permitted Behaviors

- Read `app.py`, `agents/`, `tests/`, and `README.md`.
- Run `pytest`.
- Make small scoring or UI fixes in existing files.

## Prohibited Behaviors

| Prohibition | Reason |
|------------|--------|
| Print, log, or surface secret/env values | Credential leakage |
| Auto-commit or auto-push | Needs human review |
| Delete files without explicit confirmation | Irreversible |
| Modify `.git/` directly | Corrupts history |
| Install packages globally | Pollutes system Python |
| Run destructive commands (`rm -rf`, `git reset --hard`, `DROP TABLE`) | Data loss |

## Project-specific rules

- Do not call external model APIs.
- Do not persist real user data.

## Blocked paths

- `.env`, `.env.*`, `.env.local`, `.env.production`
- `secrets.*`, `credentials.*`, `*.pem`, `*.key`
- Any file under `secrets/`, `private/`, or `credentials/`

## Escalation

If you find a committed `.env`, private key, or live credential: **stop**, report the filename only (never the value), and wait for a human.
